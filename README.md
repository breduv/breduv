## Selected projects

### [BWA](https://github.com/breduv/BWA)

A Telegram assistant that searches the web, reads sources, and remembers conversations.
Reply to an earlier message to continue a separate conversation branch.

<sub>Python · aiogram · LangGraph · MCP · SQLite</sub>

### [download-bot](https://github.com/breduv/download-bot)

Music, videos, and photo galleries delivered to Telegram.
Send a song title or a supported link, choose a track or video quality, and get the file in chat.

<sub>Python · aiogram · yt-dlp · gallery-dl · FFmpeg</sub>

### [manga-downloader](https://github.com/breduv/manga-downloader)

A desktop app for saving public MangaLib chapters as CBZ archives.
Chapter selection, a local library, and checks for new releases.

<sub>Python · PyQt5 · Windows builds · maintained fork of [BSolonenko/manga-downloader](https://github.com/BSolonenko/manga-downloader)</sub>
